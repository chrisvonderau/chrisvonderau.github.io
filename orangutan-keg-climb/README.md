# Orangutan Keg Climb

A self-contained 1980s-style browser arcade platformer. Open `index.html` in a browser and play.

Controls:

- Move: Arrow keys or WASD
- Jump: Space, J, or K
- Climb: Up and Down on ladders
- Pause: P or Escape
- Start/restart: click the game screen, Enter, or the Start button
- Xbox controller: stick/D-pad move and climb, A jump (and start), Start pause/start

The game uses custom canvas pixel art, local browser storage for high score, and no external dependencies.
